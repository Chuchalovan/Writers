# PRD — Product Requirements Document

## Обзор

**Manuscript** — веб-приложение для писателей, объединяющее редактор текста, управление структурой произведения, статистику написания и AI-помощника.

### Целевая аудитория

- Одиночные авторы (художественная и нон-художественная проза, сценарии, поэзия)
- Команды (редакции, студии) — поддержка планируется после MVP

### Языки

- Интерфейс: русский и английский (i18n с первого дня)
- Документация проекта: русский

| ID | Требование | Приоритет |
|----|------------|-----------|
| AUTH-01 | Регистрация по email + пароль | Must |

|----|------------|-----------|

| EDIT-05 | Подсчёт слов в реальном времени | Must |

| ID | Требование | Приоритет |
|----|------------|-----------|

## Нефункциональные требования

| Категория | Требование |
|-----------|------------|
| Производительность | Автосохранение без заметных задержек (< 500ms UI response) |
| Безопасность | HTTPS, хеширование паролей (bcrypt/argon2), шифрование API-ключей |
| Доступность | Базовая a11y (клавиатурная навигация, контраст) |
| Масштабируемость | Архитектура допускает cloud и self-hosted развёртывание |
| Совместимость | Chrome, Firefox, Safari, Edge (последние 2 версии) |

- Экспорт (PDF, DOCX, EPUB)
- Мобильное приложение
- Офлайн-режим
- Персонажи, локации, timeline (сущности)

## User Stories (ключевые)

### Автор-одиночка

> Как писатель, я хочу создать проект с главами, чтобы организовать своё произведение.

> Как писатель, я хочу видеть ежедневную статистику слов, чтобы отслеживать прогресс.

> Как писатель, я хочу использовать AI для правки и генерации идей, подключив свой API-ключ.

### Общие

> Как пользователь, я хочу переключать язык интерфейса между русским и английским.

> Как пользователь, я хочу, чтобы мой текст автоматически сохранялся, чтобы не потерять работу.

---

## Метрики успеха MVP

- Регистрация → создание проекта → написание первой главы: < 5 минут
- Автосохранение работает без потери данных при закрытии вкладки
- AI-запросы выполняются с пользовательским ключом без утечки на сервер
