# Эпики

Крупные темы продукта. User stories группируются по эпикам.

> Источник приоритетов: [MVP Scope Matrix](../roadmap/MVP-SCOPE-MATRIX.md)  
> Продукт: [PRD v2.0](../prd/PRD.md)

| ID | Эпик | Описание | Приоритет |
|----|------|----------|-----------|
| E-AUTH | Аутентификация | Регистрация, вход, сессия, профиль | P0 |
| E-PROJECT | Проекты | Создание/управление проектами, onboarding | P0 |
| E-STRUCTURE | Структура рукописи | Части, главы, сцены, навигатор, порядок | P0 |
| E-EDITOR | Редактор | TipTap, автосохранение, фокус, версии | P0 |
| E-KNOWLEDGE | База знаний | Персонажи, мир, сюжет, таймлайн, заметки | P0–P1 |
| E-EXPORT | Экспорт | Выгрузка рукописи и материалов | P0–P1 |
| E-AI | AI-помощь | Контекстные подсказки без автозамены текста | P1–P2 |
| E-STATS | Прогресс | Статистика, цели письма | P1–P2 |
| E-SETTINGS | Настройки | Аккаунт, проект, i18n, тема | P0–P1 |

## Связь с файлами историй

Истории лежат в [`stories/`](./stories/) с именами `US-<epic-slug>-<nnn>.md`.

Примеры slug: `auth`, `project`, `structure`, `editor`, `knowledge`, `export`, `ai`, `stats`, `settings`.
