# User Stories

Пользовательские сценарии: кто, что хочет сделать и зачем. Декомпозиция PRD для планирования и приёмки.

## Документы раздела

| Файл | Описание |
|------|----------|
| [epics.md](./epics.md) | Эпики (крупные темы) |
| [stories/](./stories/) | Отдельные user stories |
| [_template.md](./_template.md) | Шаблон новой истории |

## Формат истории

```
Как <роль>,
я хочу <действие>,
чтобы <ценность>.
```

## Приоритеты

| Метка | Значение |
|-------|----------|
| P0 | Без этого продукт не работает (Alpha / ядро) |
| P1 | Нужно для MVP Beta |
| P2 | Post-MVP / backlog |
