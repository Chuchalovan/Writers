# Техническое задание (ТЗ)

Техническая постановка: как система должна быть реализована — архитектура, контракты, данные, НФТ, политики.

Методика: IEEE 830 (SRS) в изложении [«Ликбез по техническому заданию» (Хабр)](https://habr.com/ru/articles/490006/).

## Структура ТЗ

1. Введение и границы  
2. Концептуальная модель (аудитория, роли, data flow)  
3. Функциональная карта  
4. Путь пользователя  
5. Пользовательский интерфейс  
6. Программные интерфейсы (архитектура, API, **модель БД**)  
7. Нефункциональные требования  
8. Политики (auth, редактор, ZIP-импорт, AI)  
9. Приёмка Alpha / Beta
