# Техническое задание — «Манускрипт»

> **Продукт:** «Манускрипт»  
> **Версия:** 0.1 (структура + ссылки на SoT)  
> **Дата:** 11 августа 2026  
> **Статус:** рабочий каркас  
> **Основание:** [PRD v2.0](../prd/PRD.md), [BRD v1.0](../brd/BRD.md), [User Stories](../user-stories/)

---

## 1. Назначение

Определить технические требования к веб-приложению «Манускрипт» для реализации MVP (до MVP Beta включительно).

Детальные справочники живут в [technical/](../technical/) — этот документ задаёт постановку и границы.

## 2. Объект разработки

Адаптивное веб-приложение (desktop-first) для авторов художественной прозы: проекты, структура рукописи, редактор сцен, база знаний (персонажи, мир, сюжет), экспорт, контекстный AI.

**Стек (факт):** Next.js (App Router) · PostgreSQL · Prisma · Better Auth · TipTap · next-intl · monorepo.

## 3. Состав работ

1. Реализация функциональных требований по приоритетам P0 → P1 (см. [MVP Scope Matrix](../roadmap/MVP-SCOPE-MATRIX.md))  
2. Нефункциональные требования (производительность, безопасность, i18n, доступность базового уровня)  
3. Интеграции (auth, БД, AI-провайдеры по модели из Decision Log)  
4. CI/CD, окружения, миграции  
5. Соответствие дизайн-системе (Figma → code)

## 4. Функциональные требования (сводка)

Полный перечень — в PRD и User Stories. Группы:

| Модуль | Кратко | Приоритет |
|--------|--------|-----------|
| Auth & аккаунт | Регистрация, сессия, настройки | P0 |
| Проекты | CRUD, onboarding-пути | P0 |
| Структура рукописи | Части / главы / сцены, навигатор | P0 |
| Редактор сцены | TipTap, автосохранение, метаданные | P0 |
| База знаний | Персонажи, локации, сюжет, заметки | P0–P1 |
| Экспорт | Базовый экспорт рукописи | P0–P1 |
| AI-контекст | Помощь по выбранному контексту | P1–P2 |
| Статистика / цели | Прогресс письма | P1–P2 |

Критерии приёмки — в [User Stories](../user-stories/) и gates релизов в Roadmap.
